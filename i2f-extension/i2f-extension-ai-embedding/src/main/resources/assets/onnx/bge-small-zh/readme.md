# download

- `bge-small-zh.onnx`
- you can extract from this maven lib
- because it's size about 90MB+
- i don't commit it to git 

```xml
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-embeddings-bge-small-zh</artifactId>
    <version>0.31.0</version>
</dependency>
```

- and save to your application relative path

```shell
./assets/onnx/bge-small-zh/bge-small-zh.onnx
./assets/onnx/bge-small-zh/tokenizer.json
```
