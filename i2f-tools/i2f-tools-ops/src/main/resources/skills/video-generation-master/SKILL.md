# 视频生成大师

## 概述

本技能给出 AI 短视频生成的完整打法：**多段式提示词结构** + **参考图（image-to-video）的两大失控模式及其处方** + **声音设计（BGM 与人物说话）** + **抽帧自检闸门** + **调用预算**。

**提示词形态（默认）：** Markdown 多段式——`# 定调` / `## 主体` / `## 参考锁定`（仅参考图模式）/ `## 动作` / `## 运镜` / `## 环境` / `## 声音` / `## 要求`。前七段写正文，**`## 要求` 段每一条都必须以 `【必须】` / `【重要】` / `【禁止】` 开头，出现一个"裸句子"就算不合格**。

**声音段的摆法灵活**：默认合并成 `## 声音` 一段；要素多可拆成 `## 背景音` + `## 台词`；台词与动作强耦合时可并进 `## 动作`（详见《标题怎么摆》）。

**长视频另算**：超过 10 秒要靠**末帧续写分段生成再合并**，多段 = 多次计费，**必须先经用户明确确认**才能启动（详见《长视频》）。

**两道校验都要过：** 生成前的**结构自检 9 问** + 生成后的**抽帧自检 14 项**。结构合规不等于视频合格，两层都要过——但生成后那道**只负责出检查报告，不自动重试**。

**一句话记住五件事：**
1. **先定风格**——`# 定调` 的第一个词就写风格（写实电影 / 魔幻超现实 / 赛博未来 / 国画古风……），风格在多数模型里权重最高；**没有参考图时尤其重要**，不写就会掉进"干净电商风"。
2. **声音要单独写一段**——BGM 用韵律/节奏/鼓点/BASS 描述（模型听不懂曲名），人物说话要标秒数并声明"说话不打断动作"。
3. 一次需求只调用一次，出结果 + 检查报告，然后停下等授权；
4. 参考图模式下**绝不复述参考图的外观细节**，只给"严格还原 / 一比一还原"这种抽象强指令 + 类别清单；
5. 用户说"不要参考某个部位"时，**先遮图/裁图**，再写【禁止】——"看不到"永远比"被告知别看"可靠；没有 OpenCV 就请用户人工抠图。

## 生成策略（最高优先·调用预算）

### 铁律：一次需求 = 一次调用，先出报告，再等授权

**默认只调用一次生成工具；出片后立即进入"抽帧自检 + 出第一版检查报告"，然后停下来等用户决定。未经用户明确同意，不得发起第二次生成调用。**

视频比图片贵得多、也慢得多：一次生成要 **3–5 分钟**，失败重来等于把用户的钱和时间一起烧掉。"我再调一版看看"必须由用户自己拍板。

> **红线（比铁律更硬，无例外）：**
> **用户没有明确说"重新生成 / 改这一版 / 再出一条"，就不要发起任何生成或修订动作。**
> 发现画面崩了、服装变了、风格不对——**写进报告就行，不要自作主张重跑**。判断归你，花钱的决定归用户。
> 长视频、多段续写同理：**N 段 = N 次计费，没有明确授权一段都不许加。**

**标准动作序列（四步，缺一步都算违规）：**

1. **一次调用** —— 多段式提示词写好 → 调用生成工具 1 次 → 拿到 taskUrl 后进入轮询
2. **轮询到完成** —— 见下文《轮询纪律》，**绝不因为"看起来卡住了"就重复提交**
3. **抽帧自检 + 第一版检查报告** —— 用 ffmpeg 抽 3 帧拼图，逐项比对 14 项，**只判断、不补救**
4. **停下等授权** —— 明确问用户要不要继续，用户点头后才允许第二次调用

### 轮询纪律（视频专属·防重复扣费）

| 项 | 做法 |
|---|---|
| 单次等待 | 一次 `awaitSeconds` 给 30–90 秒即可，不要一次等 5 分钟（容易超时断开） |
| 轮询间隔 | 连续查，但每次调用都实际等待；**不要写空转循环** |
| 典型耗时 | 图片 20–60 秒；**视频 3–5 分钟**（10 秒 720p 档实测 3–4 分钟） |
| 拿到 success 之后 | 立刻把 `result.fileUrl` 落盘，再抽帧自检；**别只拿 URL 不落盘**（上传链接会过期） |
| 状态一直是 running | 继续等，**不要重新提交同一个任务**（重复提交 = 重复扣费） |
| 状态 error | 把 error 原文报给用户；属于技术性失败，可重试 1 次 |

### 允许的例外（不需先请示）

只有"用户根本拿不到任何可用结果"的技术性失败，才可以不请示直接重试 **1 次**：

- 任务报错 / 超时 / 返回 0 个视频
- 文件下载失败、产出文件损坏打不开、纯黑屏/纯噪点

**以下不属于例外**（一律先问）：

- "动作不够大""脸不太像""氛围差一点"
- "想换个模型对比"
- **"想多出几条让用户自己挑" ← 最烧钱，明确禁止**

### 一次需求的默认预算

| 项 | 上限 |
|---|---|
| 生成调用（默认） | **1 次** |
| 未获同意的追加调用 | **0 次** |
| 技术性失败的重试 | 1 次（仅限结果不可用） |
| 异步任务轮询查询（不产生生成费用） | 不限，但别空转 |
| 本地后期（ffmpeg 抽帧/剪短/拼接/转码） | 不限，**不花生成费用**，可主动做 |

> **重要区分**：抽帧、剪短、拼接、压片、转竖屏这些**本地 ffmpeg 操作不产生费用**，可以放心主动做；只有"再调用一次生成模型"才要钱。

### 第一版检查报告模板（照此写，不许省略未通过项）

```
## 第一版检查结果
- 通过：主体一致性 / 服装一致性 / 动作完成 / 运镜意图 / 画面干净 / 规格 ……
- 未通过：#?  服装一致性（裙长从及膝变短裙）、#?  解剖（脚下有只悬空高跟鞋）
- 原因定位：×××（提示词里哪一句导致，还是模型先验/参考图权重）
- 建议改法：把「……」改成「……」（指名到具体那一句，或"该用预处理裁图"）
- 下一步：要我按上面的改法重出吗？（需你确认后我再调用）
```

## 第一步永远是确认风格（权重最高的一个词）

**风格是视频模型里权重最高的修饰词，必须放在提示词第一句。** 它决定光照、色彩、材质、构图、甚至动作节奏——风格没定，后面写再多细节也是浮沙。

**没有参考图（text-to-video）时这条是生死线**：不指定风格，模型会掉进默认的"干净电商风 / 网红滤镜风"，人物漂亮但毫无作品感。
**给了参考图时**风格已被图片锁定，此时改风格等于重绘场景，风险高——要么一开始就用风格相符的参考图，要么接受"人可能不像"。

| 风格 | 怎么写（放 `# 定调` 首句） | 配套要点 |
|---|---|---|
| **写实电影风** | `写实电影质感，ARRI 电影机拍摄，浅景深，冷峻自然光` | 加"颗粒感""高动态范围"；排除"塑料感" |
| **魔幻超现实风** | `魔幻超现实风格，体积光穿透雾气，画面有梦境般的失重感` | 加"漂浮元素""尺度错乱"；这类风格容错最高，崩脸也不出戏 |
| **赛博未来风** | `赛博朋克未来风格，霓虹青紫光源，湿地反光，全息投影` | 加"暗部细节""镜头光晕"；**冷暖要压住**，否则变灰 |
| **国画古风** | `中国水墨国画风格，宣纸肌理，留白构图，墨色层次` | 加"工笔细节""淡彩"；动作要慢，快动作与国画气质冲突 |
| **日系胶片** | `日系胶片写真，高调通透，轻微过曝，空气感` | 最贴日常人像；配"柔光"不配"硬光" |
| **时尚大片** | `时尚杂志大片质感，硬光造型光，高饱和，强对比` | 适合舞蹈卡点；脸部阴影重，慎用于特写 |

**写法硬规则：**
- 风格词写在 `# 定调` 的**第一个逗号之前**，不要塞到末尾
- **一个片子只选一个主风格**，混搭（"赛博朋克 + 国画"）在视频模型里基本等于没有风格
- 风格句后面紧跟**一条反向排除**：`- 【禁止】塑料感、CG 感、网红滤镜`

## 默认锚点（需求没特别说明时的基线）

用户只说"生成一个视频"、没说景别/动作/视角时，按下面这套基线走——**这是本技能的默认值，不要每次重新问用户**：

| 维度 | 默认值 | 为什么 |
|---|---|---|
| **景别** | **人物全身出镜，头顶到脚完整入画** | 舞蹈动作必须看得见全身；半身会把动作切掉一半 |
| **动作类型** | **舞蹈动作**（抖音卡点风 / 热门舞蹈风格） | 有节奏的舞蹈比"站着微动"更有看点，也是短视频的主流需求 |
| **视角** | **正面平视 / 正面弧线环绕 / 自下而上环绕上升** | 这三种最不容易穿帮（见下表） |
| **运镜幅度** | **小到中等，明确规避大幅度运镜** | 部分模型大幅运镜时画面撕裂、接缝明显 |
| **时长** | 10 秒 | 各工具默认档 |
| **画幅** | 竖屏 9:16 | 短视频场景默认 |

### 舞蹈动作怎么写才生效

**"跳热门舞蹈"这四个字对模型没有信息量**，必须翻译成可观察的身体动作 + 节奏：

```markdown
## 动作
全身入画，跟着节拍跳流行卡点舞：每 2 拍一个动作单位，
第 1 单位双脚交替点地、胯部左右摆动，手臂在胸前做上下波浪；
第 2 单位吸腿侧移半步、上臂展开，头发随动作甩动；
全程正面朝向镜头，重心低、动作干净利落。
```

- **节奏要写**：`卡点`、`每 2 拍一个动作单位`、`动作干脆利落`——不写会得到"慢动作飘舞"
- **动作要拆**：身体部位（肩/胯/手臂/脚步）+ 方向 + 次数
- **舞蹈属于 L3 大动**（见《动作幅度分级》）：一致性会掉，所以**舞蹈片默认剪到 5–7 秒交付**，或选 Kling 这类保人强的模型
- **舞蹈 + 环绕 = 最容易崩的组合**：要么固定正面机位，要么只给极轻微的推近

### 视角与运镜：优选与避雷

| 视角 | 怎么写 | 稳定性 | 说明 |
|---|---|---|---|
| **正面平视** | `固定机位，正面平视，全身入画` | ★★★★★ | 默认首选，舞蹈片就该用这个 |
| **正面弧线环绕** | `以人物为圆心做正面弧线环绕约 90°，机位与人眼同高` | ★★★ | 环绕角度**别超过 120°**，超了模型要补画面外的东西 |
| **自下而上环绕上升** | `机位从脚部高度起始，环绕上升至面部高度` | ★★★ | 很有电影感，但**最容易露出没画好的地面**；地面元素要简单 |
| **虫视仰拍** | `极低机位仰拍（虫视），镜头几乎贴地` | ★★★☆ | 用来做"巨大感"，见《特殊表达》 |
| **俯拍** | `高机位俯拍` | ★★★ | 显渺小，与"巨大"相反，别混用 |

**必须规避的大幅度运镜（会撕裂）：**

- ❌ 快速甩镜 / 急推急拉
- ❌ 180° 以上大环绕、整圈环绕
- ❌ 瞬间变焦（zoom 突变）
- ❌ 一个镜头里景别从特写拉到全身再推回

**原因：** 大幅运镜要求模型补出"参考图里根本不存在的角度"，它只能编——编不出来就是撕裂、接缝、结构塌陷。**要动，靠主体动作；不要靠镜头。**

### 特殊表达技巧（想要某种效果时这么写）

| 想要的效果 | 怎么写 | 配套 |
|---|---|---|
| **面部情绪 / 微表情** | `超近距离面部特写，只拍到眉眼与鼻唇，皮肤纹理与睫毛清晰可见` | 加"眼神光""微表情变化"；**特写不与大动作同用** |
| **人物巨大（泰坦感）** | `泰坦一样巨大的身躯占满整片天空，虫视仰拍，地标建筑只到她脚踝` | 必须有**体量参照物**（人/车/树/楼），否则"巨大"读不出来 |
| **人物渺小** | `极远景俯拍，人物只占画面二十分之一` | 与"巨大"相反，别写混 |
| **速度感** | `轻微动态模糊与运动拖影` | 慎用，容易糊成一团 |
| **情绪收尾** | `镜头停在面部，眼神光渐亮` | 适合当片尾 2 秒 |

> **"巨大"的正确写法是尺度对比 + 视角，不是形容词。** 只写"巨大的女人"会得到"一个普通女人"；写"虫视仰拍 + 楼只到脚踝"，模型才会真的把她放大。

## 声音设计（BGM + 人物说话）

**绝大多数视频模型带音轨能力**（返回里能看到 `audio: true`），音轨不是"附带产物"，是可以写提示词去控制的。但它有两套完全不同的写法规则，混着写就两头落空。

**默认策略：**

| 场景 | 默认做法 |
|---|---|
| 舞蹈 / 卡点 / 时尚片 | **必须写 BGM**，否则模型给随机音或干脆静音 |
| 有人物出镜、要情绪 | 写一句台词 + 声线情绪（短句，5–12 字） |
| 只要画面、不要声音 | `- 【禁止】任何人声与配乐`，或本地 `ffmpeg -an` 去掉 |
| 模型明确不支持人声 | 只写 BGM，台词交后期 TTS 配音 |

### 标题怎么摆：三种摆法都合法，按需灵活调整

声音**不强制塞进一段**。下面三种摆法都对，按片子复杂度选：

| 摆法 | 结构 | 适合 |
|---|---|---|
| **A. 合并为一段** | `## 声音`（BGM + 台词写在一起） | 默认，10 秒短片够用，最省事 |
| **B. 拆成两个标题** | `## 背景音` + `## 台词`（或 `## 说话`） | BGM 描述较长、台词要标秒数，拆开更清楚、权重也更独立 |
| **C. 台词并入动作** | `## 动作` 里写台词，另起 `## 背景音` | 台词和身体动作强绑定时（边说边跳、边转身边说话），放一起更容易被理解成同一件事 |

**选择原则：**
- **默认用 A**；声音要素超过两行、或台词要精确标秒 → 用 B
- **动作与说话高度耦合**（口型跟着动作走）→ 用 C，但**必须在同一句里写"边……边说"**，不要写成"先……再……"
- 无论哪种摆法，**三件事不能少**：说什么（台词）、何时说（秒数）、怎么说（声线/情绪/语速）
- 无论哪种摆法，**BGM 都只写音乐要素**（BPM/风格/鼓点/低频/情绪），不写曲名

> **灵活不等于省略。** 摆法可以随意，但"台词 + 秒数 + 声线"和"BPM + 风格 + 鼓点"这两组信息量必须齐。

**C 摆法的写法示例（台词并进动作，必须写成"边……边说"）：**

```markdown
## 动作
全身入画跳卡点舞，动作干脆；第 3 秒起边跳边说一句「今天风真好」，
清亮女声、含着笑、语速偏快；说话不打断动作，口型与胯部动作同时进行。
```

**B 摆法的写法示例（拆两段）：**

```markdown
## 背景音
120BPM 电子舞曲，强劲四拍底鼓踩点、厚实 808 BASS、明亮合成器琶音；
人声靠前、配乐压低，情绪燃而松弛。

## 台词
第 3 秒开口说「今天风真好」，清亮女声、含着笑、语速偏快，说完继续跳不中断动作。
```

### BGM：用音乐要素描述，不要写曲名

**模型不认识曲名。** 写"用《XXX》"对它来说等于一个没有声学含义的符号，出来的是随机音。必须翻译成可执行的音乐要素：

| 要素 | 可用词 |
|---|---|
| **节奏 / 速度** | `120BPM`、四四拍、强劲四拍踩点、碎拍、半速（half-time） |
| **韵律 / 律动** | 卡点、切分、摇摆律动（swing）、循环 hook |
| **风格** | 电子（EDM / trap / house）、国风电子、Lo-fi、City pop、史诗管弦、赛博合成器、民乐（古筝/琵琶/笛） |
| **低频** | 厚实 BASS、808 低频、低频下潜、BASS 打点 |
| **鼓组** | 底鼓重击、军鼓、踩镲滚奏、鼓点干脆 |
| **音色** | 明亮合成器琶音、失真电吉他、弦乐铺底、环境氛围层 |
| **混音** | 人声靠前、配乐压低、留白 |
| **情绪** | 燃、慵懒、治愈、紧张、宏大、怀旧 |

**可抄的一行成品：**

```
BGM：120BPM 电子舞曲，强劲四拍底鼓踩点、厚实 808 BASS 打点、明亮合成器琶音铺底，
人声靠前、配乐压低两档，情绪燃而松弛。
```

**三条硬规则：**
- **BPM + 风格 + 鼓点/低频** 三样必须给，缺一样就容易得到"通用罐头音"
- **配乐要服务剪辑**：卡点舞蹈写"每 2 拍一个重击"，让动作和鼓点对得上
- **别写曲名、别写歌手、别写歌词**——那是"点歌"，模型做不到，还会挤占画面描述

### 人物说话：三件事说清（说什么 / 何时说 / 怎么说）

| 要素 | 怎么写 | 说明 |
|---|---|---|
| **说什么** | 直接给台词 `说一句「今天的风真好」` | 5–12 字最稳；超过 15 字容易吞字、口型乱 |
| **何时说** | `第 3 秒开始说，持续到第 5 秒` | **必须标秒**，不标就变成全片一直在说 |
| **怎么说** | `清亮女声、含着笑、语速偏快、气声收尾` | 声线 + 情绪 + 语速，三样给两样就够 |

### 关键问题：说话与动作互斥

**症状（实测高频）：** 一让角色说话，舞蹈就停了；一跳舞，嘴就闭上了。像两个开关只能开一个。

**根因：** 模型把"口型驱动"和"骨骼动作"当成两个互相抢占资源的目标，先锁哪个就只剩下哪个。加上"然后""说完再"这类时序词，等于明确告诉它"排队做"。

**处方（按有效性排序）：**

1. **写"并行"，删掉一切时序词** —— `说话的同时保持动作不中断`、`口型与舞蹈同时进行`；**禁用**"先说话再跳""跳完再说"这种排队式表达
2. **按秒把两件事叠在同一段时间上** —— 不是"0-3 秒跳、3-6 秒说"，而是"3-6 秒**边跳边说**这句"
3. **在 `## 要求` 加硬约束**（这条最管用）：
   - `- 【必须】说话不打断动作，口型与肢体动作同时进行`
   - `- 【禁止】说话时动作停止、口型与动作不同步`
4. **给动作降级** —— 口型 + 大动作是双任务。舞蹈从 L3 降到 L2（幅度减小、节奏放缓），成功率明显提高
5. **真要两全就拆两条** —— 一条纯舞蹈、一条特写说话，后期剪辑。**比一次硬要省时间也省钱**

### 声音段的标准写法

```markdown
## 声音
BGM：120BPM 电子舞曲，强劲四拍底鼓踩点、厚实 808 BASS、明亮合成器，人声靠前、配乐压低，情绪燃而松弛。
人物说话：第 3 秒起说一句「今天的风真好」，清亮女声、含着笑、语速偏快；
边说边跳，说话不打断舞蹈动作，口型与身体动作同时进行。
```

对应的 `## 要求` 收口：

```markdown
- 【必须】说话与动作同时进行，口型与肢体动作同步
- 【禁止】说话时动作停止、口型与身体不同步
- 【禁止】字幕、水印、气泡文字
```

### 音轨的本地补救（不花生成费用）

模型给的音轨不满意时，优先本地处理，别重新生成：

```bash
ffmpeg -y -i in.mp4 -an -c:v copy silent.mp4                     # 去掉原音轨
ffmpeg -y -i in.mp4 -i bgm.m4a -shortest -c:v copy -c:a aac out.mp4  # 换自己的 BGM
ffmpeg -y -i in.mp4 -i tts.wav -filter_complex "[1:a]adelay=3000|3000[a]" -map 0:v -map "[a]" -c:v copy out.mp4  # 第 3 秒插入配音
```

> **判断原则：** 画面对了、声音不对 → **本地换声音**；画面也不对 → 才考虑重生成（且要用户放行）。

## 提示词结构规范（多段式·默认写法）

### 标准形态（照此抄）

```markdown
# 定调：写实电影质感，<场所 / 季节 / 光线 / 色调 / 情绪，≤30 字>

## 主体
<族裔/五官/肤色/年龄/身形/发型 —— 文生视频才写全；参考图模式只写"以参考图为准">

## 参考锁定
<仅参考图模式：严格沿用参考图；类别清单（头饰/手饰/发色/服装颜色与款式/腿饰/鞋）；不改不增删>

## 动作
<主体动作（幅度写清楚）+ 身体朝向 + 手部位置 + 表情变化 + 动作发生在第几秒；
 默认：全身入画 + 舞蹈卡点动作>

## 运镜
<一个主运镜（推/拉/正面弧线环绕/自下而上环绕上升/升降/摇移/手持）+ 起止位置 + 速度 + 焦点；
 默认：正面平视或轻微推近，规避大幅运镜>

## 环境
<季节与场所 + 天气与时间 + 主体受光 + 环境调性 + 2-4 个季节道具 + 光影痕迹>

## 声音
<BGM：BPM + 风格 + 鼓点/低频 + 情绪；人物说话：第几秒 + 台词 + 声线情绪语速；声明"边说边做、不打断动作">
（亦可拆成 ## 背景音 + ## 台词，或把台词并入 ## 动作，见《标题怎么摆》）

## 要求
- 【重要】画面清晰，真实摄影质感，与定调的风格一致
- 【必须】主体全身入画，头顶到鞋跟完整
- 【必须】主体、服装、配饰与参考图一致
- 【禁止】重新设计服装、改变裙长、更换鞋款
- 【禁止】脸部崩坏、五官漂移、多余手指
- 【禁止】画面撕裂、接缝、结构塌陷
- 【必须】说话与动作同时进行，口型与肢体动作同步（有台词时）
- 【禁止】说话时动作停止、字幕、水印
- 【重要】竖屏 9:16
```

### 八个段落的职责边界（顺序不可调换）

| 顺序 | 段落 | 装什么 | 不许混进来的东西 |
|---|---|---|---|
| 1 | `# 定调` | **风格首词** + 一句话总基调（季节、场所、光线、色调、情绪） | 具体服装、具体动作 |
| 2 | `## 主体` | 人本身：族裔/五官/肤色/年龄/身形/发型/服装 | 运镜、环境 |
| 3 | `## 参考锁定` | 参考图要沿用的**类别清单** + 还原强度 | **参考图的具体外观描述**（见下节铁律） |
| 4 | `## 动作` | 姿态变化、手部位置、表情、动作在第几秒 | 运镜（属下一段） |
| 5 | `## 运镜` | 镜头怎么动、往哪动、多快、焦点跟谁 | 主体动作 |
| 6 | `## 环境` | 季节场所、光照两层、道具、光影痕迹 | 人物五官 |
| 7 | `## 声音` | BGM 的音乐要素、台词内容、说话秒数、声线情绪 | 曲名/歌手/歌词；动作细节 |
| 8 | `## 要求` | 硬性收口：一致性、解剖、构图、规格、音画同步、排除项 | 新的场景参数 |

**为什么把 `## 运镜` 单列一段：** 视频模型对"镜头怎么动"和"人怎么动"是两套权重。混在一句里（"镜头推近，她微笑"）会互相稀释，最后要么不动、要么乱动。**分开写，一段只交代一件事。**

**为什么声音推荐单列、但允许灵活（见《标题怎么摆》）：** 声音和画面在模型里是两条独立的生成通道，**塞进 `## 动作` 里容易被当成"动作的一部分"而互斥**（一说话就不动）。默认单列 `## 声音` 最省事；声音要素多就拆成 `## 背景音` + `## 台词`；只有"口型跟着动作走"这种强耦合场景，才把台词并进 `## 动作`（且必须写"边……边说"）。**摆法自由，信息量不自由。**

**为什么 `## 主体` 必须在 `## 动作` 前面：** 模型对越靠前的内容权重越高。身份信息被推到中后段就会被动作词冲淡，出来的脸最先跑偏。

### 着重标记体系（前缀是硬要求）

| 标记 | 管什么 | 判失败的标准 | 典型用法 |
|---|---|---|---|
| `【必须】` | 不可协商的硬约束 | 缺了就算不合格 | `- 【必须】主体面部与参考图一致，五官不得漂移` |
| `【重要】` | 高权重但可微调 | 明显偏了要改提示词 | `- 【重要】画面清晰，真实摄影质感` |
| `【禁止】` | 明确排除 | 出现即不合格 | `- 【禁止】重新设计服装、改变裙长` |

**六条用法硬规则：**

1. **前缀写在句首**，紧跟被约束的内容；禁止写成"人物要一致（必须）"这种尾注——读到句尾时权重已经分配完
2. **一句一个前缀**，禁止叠用（`【必须】【重要】`）
3. **每条 `【禁止】` 尽量配一条正面兜底的 `【必须】`**：只写"禁止换脸"模型容易照做反义，要同时写"面部与参考图一致"
4. **同一维度先正后反**：先写要什么，再写不要什么
5. **一条 `【禁止】` 不超过 3 个排除项**，超过就拆条，长排除串会互相稀释
6. **`## 要求` 段 6–10 条为宜**；满屏 `【必须】` 等于没有 `【必须】`

### 时间轴分段写法（动作复杂时才用）

10 秒片子塞不进三个动作。需要多个动作时，在 `## 动作` 里给时间轴：

```markdown
## 动作
0-3 秒：坐在栏杆边，微微抬眼看向镜头，唇边笑意加深；
3-6 秒：抬起右手轻扶身旁栏杆，长发被风带起；
6-10 秒：保持这个姿态，只有呼吸与发丝轻动。
```

**经验值：10 秒最多 2 个动作，第 3 个动作必然导致末段一致性崩坏。**

## 参考图模式（image-to-video）· 本技能核心

参考图一旦给进去，模型行为就变了：**它会把参考图当"必须复刻的画面"，而不是"风格参考"。** 由此产生两种典型失控，处理方式完全不同。

### 两条铁律（先记住，再看处方）

> **铁律一：不要用文字复述参考图的外观。** 你写"淡青色雪纺细吊带连衣裙、裙摆膝上十厘米"，模型就会在"文字描述"和"参考图"之间做折中，生成一个既不等于图、也不等于文字的第三种东西。**只给抽象强指令（严格还原/一比一还原），不给具体内容。**
>
> **铁律二：模型会为了复刻参考图而忽略用户的其他要求。** 用户说"脸换一个""鞋换一双"，模型照样照搬。**文字否定压不住参考图权重，物理上让模型看不到，才压得住。**

### 失控模式 A：服装细节被丢失 / 被"重新设计"

**症状：** 参考图里明明有精致吊带、有印花、有腰间细带、有一双系带高跟，生成出来变成一件"大概浅色的连衣裙"，鞋换了款，项链变粗，头饰消失。

**三条根因（常常同时发生）：**

1. **提示词里写了具体服装描述** → 文字与图冲突，模型折中，细节被"平均"掉
2. **服装是每帧重画的对象** → i2v 只在首帧强绑定参考图，往后逐步解绑，**越到片尾越不像**
3. **动作词抢走了注意力** → 写了"风吹裙扬""转身""抬手"，模型把算力放在运动上，服装退化成"一件浅绿裙子"

**处方（按优先级，1→4 依次加码）：**

| 级别 | 做法 | 写法示例 |
|---|---|---|
| 1 | **不给描述，只给抽象强指令** | `## 参考锁定`：`人物、服装、配饰、发型、鞋款全部严格沿用参考图，不要重新设计` |
| 2 | **清单式锚定：只点类别，不点内容** | `逐项保持参考图中的：头饰、耳饰、项链、发色与发型、服装颜色与款式、腰间细节、腿饰、鞋款与鞋跟高度` |
| 3 | **还原度不够就升级措辞** | `一比一还原参考图中的服装与全部配饰，不得增删改任何一件` |
| 4 | **加反向排除** | `- 【禁止】重新设计服装、改变裙长与裙型、更换鞋款、增减配饰` |

**关键认知：清单式锚定的作用不是"告诉模型长什么样"，而是"告诉模型这些地方必须盯住"。**

对照一下两种写法的后果：

```markdown
# ❌ 错误：复述了参考图的外观
## 主体
身穿淡青色雪纺细吊带连衣裙，裙摆短至膝盖上方十厘米，脚踩米白色细带露趾高跟凉鞋。
# 后果：模型在"你写的裙子"和"图里的裙子"之间折中，裙子被改版

# ✅ 正确：只锁类别，不写内容
## 参考锁定
服装、配饰、发型与鞋款严格沿用参考图，一比一还原，不要重新设计。
逐项保持：头饰、耳饰、项链、发色、服装颜色与款式、腿饰、鞋款与鞋跟高度。
```

**还有一条加分动作：** 服装漂移程度与**动作幅度**正相关。同样的参考图，配"微动 + 缓慢推近"几乎不漂；配"大动作 + 环绕"必然漂。**要保服装，就先压动作。**

### 失控模式 B：参考图"劫持"了用户的其他要求

**症状：** 用户明确说"脸不要用参考图的，按我描述生成"，结果出来还是同一张脸；说"鞋子换成短靴"，出来还是原来那双凉鞋；说"腿部服饰去掉"，丝袜还在。

**两条根因：**

1. **参考图权重 >> 文字权重**，尤其在 i2v 里参考图是"像素级约束"
2. **文字否定在视觉模型里经常被理解成"存在"**——写"不要墨镜"，模型反而先想起墨镜

**处方（两条腿走路，顺序不能反）：**

#### 第一步：预处理参考图（首选，物理隔离）

用本技能自带的 `scripts/prep_reference.py` 把不想被参考的部位**遮掉或裁掉**——模型看不到，就抄不过去。

| 用户诉求 | 处理方式 | 命令要点 |
|---|---|---|
| 不要参考**面部**（要换脸/换妆） | mask 头部横带，重模糊 | `--preset face` |
| 不要参考**鞋** | mask 脚部横带 | `--preset shoes` |
| 不要参考**腿部服饰**（丝袜/腿环/绑带） | mask 腿段 | `--preset legwear` |
| 不要参考**头饰/发型** | mask 头部横带 | `--preset head` |
| 只要衣服和姿态，头和脚都不要 | crop 保留躯干段 | `--mode crop --rect 0.06,0.28,0.96,0.86` |
| 整体换一个人 | **换一张参考图**，别硬改 | — |

```bash
# 例：不参考面部与鞋，其余构图全部保留
python scripts/prep_reference.py -i ref.png -o ref_noface_noshoe.png \
       --preset face,shoes --fill blur

# 例：只要中段（躯干 + 裙），头与脚直接裁掉
python scripts/prep_reference.py -i ref.png -o ref_torso.png \
       --mode crop --rect 0.06,0.28,0.96,0.86

# 例：先出预览确认框位置对不对（不产出成品）
python scripts/prep_reference.py -i ref.png -o /tmp/x.png \
       --preset face,shoes --preview /tmp/boxes.png --preview-only
```

**预处理的三条纪律：**

1. **优先 mask，不要 crop**。crop 会改构图与画幅，模型可能顺手把人物重排；mask 保留构图，只掐掉细节。
2. **宁大勿小，用"横向整条带"而不是紧框**。人物在画面里的水平位置不固定，紧框经常一边漏半张脸、或者把下巴留在框外——**漏了等于白做**。代价是会连带糊掉一点背景，值。
3. **产出必须肉眼复核**。内置预设只是起点（按竖屏全身人像标定），人物偏左偏右、半身构图、俯拍仰拍都要改用 `--rect` 自己给框。**没复核就上传，等于没做。**

> **可选升级**：需要自动化人脸定位时可以接 OpenCV 的 Haar/DNN 检测器（`cv2.data.haarcascades`），但生成图的人脸检测并不稳定，**检测不到就 fallback 到横带预设**，别让流水线卡死。

#### 没有 OpenCV / 不能本地处理时：请用户人工预处理

不是每台机器都装得动 `opencv-python`，素材也常常在用户手上拿不到本地路径。这时**不要硬用文字去压参考图**（压不住），而是**把抠图这件事交给用户，一次说清要抠什么**。

**做法（三步，不要来回问）：**

1. **列清单**：部位 + 范围 + 处理方式 + 保留什么，一次给全
2. **给最低成本的操作建议**：手机相册的"涂鸦/马赛克"、微信截图的马赛克、Windows 画图的填充、在线修图工具——**不要求用户装软件**
3. **说清验收标准与后续**：处理完发回来，我再提交生成（**这一步不产生生成费用**）

**可以直接发给用户的模板：**

```
请你在参考图上处理掉下面这几处，其余原样保留：
1) 面部 —— 从头顶到下巴（含头发）：用马赛克或重模糊盖掉，脸的轮廓大小要留着
2) 鞋子与双脚 —— 画面最下方约 15%：同样盖掉
3) 不要裁切、不要改画幅比例、人物位置不要移动、不要调整亮度

处理完把图发我，我再提交生成（这步不花钱）。
```

**验收三条（用户发回来后先自己看）：**

| 检查 | 不合格的表现 |
|---|---|
| 该遮的部位**看不出原样** | 还能看出五官/鞋款细节 → 让用户加重模糊 |
| **构图没变** | 人物被裁掉一截、画幅比例变了 → 模型会重排画面 |
| **边缘别用硬矩形** | 明显的黑色色块会变成"贴纸"跟着动 → 让用户用模糊而不是纯色块 |

**退一步的两个方案（用户不愿抠图时）：**

- **换参考图**：找一张本来就没有该部位（或不强调该部位）的图，比抠图更省事
- **转纯文字生成**：放弃参考图，按《第一步永远是确认风格》+ `## 主体` 写全新人物——**没有参考图就没有劫持，也就不需要预处理**

#### 第二步：`## 要求` 段写"正面声明 + 反面排除"双重句

预处理之后**仍然要写**，因为模型会自己"脑补"回来：

```markdown
- 【必须】面部按用户要求重新生成，五官与妆容不要沿用参考图
- 【禁止】沿用参考图的面部特征
- 【必须】鞋款改为黑色短靴，不要沿用参考图中的凉鞋
- 【禁止】出现参考图中的露趾凉鞋与脚背系带
```

**预处理后的一条重要纪律：被遮住的部位，不要再写任何外观描述。** 要么完全不提，要么只写"按用户要求"——写了具体描述，模型就会按文字重画，反而更乱。

### 决策表：先判断"是 A 还是 B"

| 用户的话 | 属于 | 先做什么 |
|---|---|---|
| "衣服怎么变了/细节没了" | A | 删掉服装描述 → 改清单式锚定 → 加"一比一还原" → 压动作幅度 |
| "鞋不对/裙子太长/配饰丢了" | A（局部） | 同上 + `--preset` 之外用 `--rect` 精确定位到该件物品 |
| "脸不要用这张的" | B | `--preset face` 遮脸 → 要求段双重句 |
| "我要换成另一个人的脸" | B | 遮脸 + `## 主体` 里把新脸写全（此时**必须**写具体描述，因为要覆盖参考图） |
| "腿部服饰去掉" | B | `--preset legwear` → 要求段双重句 |
| "场景要换但人不变" | A/B 混合 | 参考图只留人（crop 到人物）+ 环境段重写 |

> **注意 B 类的例外**：当用户要"换成另一张脸"时，`## 主体` 里**必须**写全新面孔的具体描述——因为此时目标是覆盖参考图，而不是沿用。这与铁律一不矛盾：铁律一说的是"不要复述参考图"，不是"永远不写人物描述"。

### 参考图模式的标准提示词模板

```markdown
# 定调：<风格首词 + 场所/季节/光线/色调/情绪，≤30 字>

## 主体
<仅写"需要与参考图不同"的部分；参考图要沿用的部分不写>

## 参考锁定
人物长相、服装（颜色/款式/长度/面料）、配饰（头饰/耳饰/项链/手饰）、发色与发型、腿饰、鞋款与鞋跟高度，
全部严格沿用参考图，一比一还原，不要重新设计，不要增删任何一件。

## 动作
<单一动作 + 幅度 + 发生秒数 + 手部位置（避开面部，防墨镜/遮挡）>

## 运镜
<一个主运镜 + 速度 + 起止景别 + 焦点>

## 环境
<季节场所 + 主体受光 + 环境调性 + 道具 + 光影痕迹>

## 声音
<BGM：BPM + 风格 + 鼓点/低频 + 情绪；台词：第几秒 + 内容 + 声线；声明边说边做不打断动作>
（可拆成 ## 背景音 + ## 台词，或并入 ## 动作，见《标题怎么摆》）

## 要求
- 【重要】画面清晰，真实摄影质感，<竖屏/横屏> <比例>
- 【必须】主体与参考图一致，五官不得漂移
- 【必须】服装、配饰、鞋款与参考图一致，不得改款改长
- 【禁止】重新设计服装、更换鞋款、增减配饰
- 【禁止】脸部崩坏、五官漂移、多余手指、肢体扭曲
- 【禁止】路人、文字、水印、画面跳变
- 【必须】说话与动作同时进行，口型与肢体同步（有台词时）
- 【禁止】说话时动作停止
```

## 可用模型（按擅长分工）

| 模型 | 擅长 | 运镜偏好 | 一致性 | 实测备注 |
|---|---|---|---|---|
| **Kling**（kling-v3-omni） | 写实人物、微表情、稳定小幅运动 | 匀速推/拉、轻微手持 | ★★★★★ | 人物最稳、脸几乎不漂；动作偏保守，容易"太静"；末段常收在特写 |
| **Vidu**（viduq3-pro img2video） | 氛围流动、柔和环绕、前景视差 | 弧线环绕、升降、前景遮挡 | ★★★☆ | 空间感最电影；但会把服装与建筑"重做"（裙长漂移、栏杆重建、脚-鞋错位） |
| **PixVerse**（pixverse-v6-it2v） | 大动态、冲击力、光斑 bokeh | 低角度快推、环绕、speed ramp | ★★☆ | 视觉最抓人；**末 2–3 秒容易换脸**，适合剪短用 |
| **Happy Horse**（快乐马） | 中文国风语义、写实场景 | 中规中矩 | 待验证 | 中文场景描述理解好，实测样本少，先小成本试 |

**选型口诀：要保人 → Kling；要氛围 → Vidu；要冲击 → PixVerse；要国风中文 → Happy Horse。**

**音轨能力**：四家实测返回的成片都带音轨（`audio: true`），BGM 用音乐要素描述基本能生效；**人声支持程度不一**，别把"一定会说话"当成必然——没有把握时先只写 BGM，台词交后期 TTS。

## 运镜词表与动作幅度分级

### 常用运镜（一条片子只用一个主运镜）

| 运镜 | 中文写法 | 风险 |
|---|---|---|
| 推 | `镜头从全身缓慢匀速推近到半身` | 推过头收在面部特写，人物占比过大 |
| 拉 | `镜头从半身缓慢拉远露出全身与环境` | 拉开后背景穿帮（模型补不出景） |
| 环绕 | `以人物为圆心做缓慢弧线环绕，前景荷叶做视差` | **场景建筑最容易被重建**，慎用于有明确建筑结构的画面 |
| 升降 | `镜头轻微升高/降低` | 幅度过大会露出没画好的地面 |
| 摇移 | `镜头横向平移，带出湖面全景` | 平移会暴露背景接缝 |
| 手持 | `轻微手持呼吸感` | 抖过头变"手持晃"，反而廉价 |
| 变速 | `裙摆扬起瞬间略作慢动作（speed ramp）` | 模型常做不出来，只当锦上添花 |

**写法要点：** 一个主运镜 + 一个景别起止 + 一个速度词（缓慢/匀速/快速），三样齐了就够；再加就失控。

### 动作幅度分级（决定一致性能不能保住）

| 级别 | 动作 | 一致性 | 适用 |
|---|---|---|---|
| **L1 微动** | 呼吸、眨眼、发丝与裙摆 1–3cm 摆动、笑意加深 | ★★★★★ | 保人物、保服装、商业展示 |
| **L2 中动** | 转头 30–60°、抬手扶栏杆、起身一半、侧身 | ★★★☆ | 有情绪、要动态 |
| **L3 大动** | 起身走动、转身、风吹裙扬、跑步、跳跃、**跳舞** | ★★☆ | 短片段/氛围片，**接受末段崩** |

**一致性衰减规律（实测）：动作幅度 × 时长 = 一致性损失。**
10 秒片子里，L3 动作在第 8 秒后基本"换人"或"换衣"。**所以：大动作只放前 3 秒，后面交给运镜收尾。**

**舞蹈是 L3，且是"持续 L3"——它不停，所以衰减最快。** 舞蹈片的三条配套：

1. **剪短**：成片默认 5–7 秒交付，10 秒原片只当素材
2. **选模型**：优先 Kling（保人最强），PixVerse 的舞蹈片末段基本必崩
3. **别叠环绕**：舞蹈 + 环绕 = 双重衰减。用固定正面机位或极轻微推近，动作交给身体

## 规格与时长

| 项 | 默认 | 说明 |
|---|---|---|
| 方向 | `portrait_mode: true` → 竖屏 | 输出典型 720×1272 / 720×1280 |
| 时长 | 10 秒 | 各工具默认档 |
| 帧率 | 24fps | 固定 |
| 分辨率 | 720p 档 | 更高档更慢更贵，按需 |
| 音轨 | 多数工具带 `audio: true` | **可以写提示词控制**（BGM + 人声）；不满意就本地替换，别为声音重生成 |

**超过 10 秒怎么办：** 走《长视频：末帧续写 + 合并》，**不要指望一次出 20 秒**（一致性与时长成反比），**且必须先拿到用户的明确授权**。

```bash
# 转竖屏裁切（横屏片源 → 9:16 中心裁切）
ffmpeg -y -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920" -c:v libx264 -crf 20 out.mp4
```

## 长视频：末帧续写 + 合并（必须先获授权）

### 授权闸门（这一步不能跳）

单次生成只有 10 秒量级，**超过 10 秒必然是多段生成 + 多次计费**。所以：

> **铁律：用户没有明确说"要长视频 / 要 XX 秒 / 要多段"，就不得启动多段流程。**
> **铁律：用户没有明确说"改 / 重出"，就不得发起任何生成或修订。**

启动前必须先给出**分段计划**并等确认，格式：

```
计划：总时长 30 秒 = 3 段 × 10 秒，需 3 次生成调用（约 3 × 3–5 分钟）
第 1 段：<动作/镜头>
第 2 段：接第 1 段末帧，<动作/镜头>
第 3 段：接第 2 段末帧，<动作/镜头>
确认后我先只做第 1 段，出结果再问你要不要继续。
```

**默认按"一段一确认"推进**（最省钱）；用户如果一次性授权 N 段，要把"已授权段数"明确记下来，**不得超批**。

### 五步流程

| 步 | 做什么 | 要点 |
|---|---|---|
| 1 | **规划分段** | 每段 8–10 秒最稳；**建议总段数 ≤ 4**，段数越多越漂 |
| 2 | **生成第 1 段** | 首帧用原图（i2v），或纯文字生成 |
| 3 | **抽末帧（挑最清晰的）** | 见下节，**不要直接取最后一帧** |
| 4 | **末帧续写第 2 段** | 把末帧当 `reference_image_url`，提示词写"接续" |
| 5 | **合并 + 接缝自检** | `concat` 或 `xfade`，再逐项对 |

### 第 3 步：为什么不能直接取最后一帧

**视频的最后一帧经常是糊的**——运镜还没停、运动模糊、编码拖影。拿它当下一段首帧，等于把"糊"传染给整段。

正确做法：**在最后 3 秒里按 4fps 采样十来帧，挑拉普拉斯方差最大的那帧**（数值越高边缘越锐），同时排除过暗/过曝帧（纯黑收尾、闪白转场）。

```bash
# 在最后 3 秒采样，取最清晰 1 帧
python scripts/pick_tail_frame.py -i part1.mp4 -o tail1.png --seconds 3 --fps 4

# 先看打分再决定（不落盘）
python scripts/pick_tail_frame.py -i part1.mp4 --list --seconds 3 --fps 6

# 导出前 3 名人工再挑
python scripts/pick_tail_frame.py -i part1.mp4 -o tail1.png --top 3
```

脚本会打印每个候选帧的 `score / laplacian / mean`，并告诉你最终选了第几帧。**实测发现**：一段 10 秒片子最后 3 秒里，最清晰的一帧往往出现在窗口**开头**（越到结尾越糊），所以"直接取最后一帧"几乎必踩坑。

### 第 4 步：续写提示词怎么写

续写段的核心不是"重新描述画面"，而是**声明连续性**。模板：

```markdown
## 参考锁定
参考图是上一段的最后一帧。人物、服装、配饰、场景、光线与机位完全延续，
不要跳变、不要重新构图、不要重新设计。

## 动作
从参考图的姿态**继续**动作，不要从头开始；前 1 秒不出现姿态突变或重新站定。

## 运镜
延续参考图的机位与景别，只做极轻微的推进或静止，不要切换镜头。
```

**三条禁忌：**
- ❌ 写"从站姿开始""人物转身"——模型会重排人物，出现"重来一遍"的穿帮
- ❌ 重写人物外观（违反参考图铁律，还会引起服装漂移）
- ❌ 换运镜（上一段在推，这一段突然环绕 → 接缝必然跳）

### 第 5 步：合并命令

```bash
# 1) 同规格直接拼（最快，不重编码）
printf "file 'part1.mp4'\nfile 'part2.mp4'\nfile 'part3.mp4'\n" > list.txt
ffmpeg -y -f concat -safe 0 -i list.txt -c copy long.mp4

# 2) 消接缝：相邻段交叉淡化 0.3 秒（需重编码；两两串联）
ffmpeg -y -i p1.mp4 -i p2.mp4 \
  -filter_complex "[0:v][1:v]xfade=transition=fade:duration=0.3:offset=9.7[v]" \
  -map "[v]" -c:v libx264 -crf 20 -pix_fmt yuv420p seg12.mp4

# 3) 规格不一致先统一（分辨率/帧率/像素格式），再拼
ffmpeg -y -i in.mp4 -vf "scale=720:1272,fps=24" -pix_fmt yuv420p norm.mp4
```

**注意：** `-c copy` 拼接要求段与段编码参数完全一致，否则花屏、时长错乱、音画不同步——**不一致就先 `norm` 再拼**。

### 段间接缝自检（长视频专用 5 项）

| # | 项 | 判据 |
|---|---|---|
| 1 | **人物连续** | 上一段末帧 vs 下一段首帧，是不是同一人、同一妆 |
| 2 | **服装连续** | 裙长、配饰、鞋款没变（累积漂移在这里最明显） |
| 3 | **场景连续** | 栏杆、亭柱、荷花位置没跳 |
| 4 | **光线连续** | 色温与明暗没有突变 |
| 5 | **动作连续** | 姿态是"接着做"，不是"从头再来"（最容易被看穿的穿帮） |

**做法：** 把"上一段末帧"与"下一段首帧"并排看（`ffmpeg` 抽首帧后用图像工具拼），**比单看整段视频更容易发现跳变**。

### 常见失败与处理

| 症状 | 处理 |
|---|---|
| 下一段首帧糊 | `pick_tail_frame.py` 重挑；`--seconds 4` 放宽窗口；或退到"最后 5 秒最清晰帧" |
| 姿态跳变、"重来一遍" | 提示词加"从参考图姿态继续，不要从头开始"；动作降到 L1；`【禁止】重新站定、切换构图` |
| 越接越不像（累积漂移） | 段数压到 2–3 段；每段抽帧后复核服装；必要时回到原图重开一条（要用户同意） |
| 拼接花屏 / 音画不同步 | 先 `norm` 统一编码参数，再 `concat`；或直接 `xfade` 重编码 |
| 接缝处"闪一下" | 用 `xfade` 交叉淡化 0.3–0.5 秒（硬切最容易露馅） |

### 费用纪律（再强调一次）

- **N 段 = N 次调用**，每段 3–5 分钟；开场就把"总段数 / 已批段数 / 还剩几次"写清楚
- 每段出完 → **停下出检查报告** → 等用户确认再做下一段
- **未经明确授权：不生成、不修订、不"顺手多补一段"**
- 中途想改风格/动作 → 说明"这会作废已生成的段，从第几段重来"，让用户决定

## 生成前结构自检（9 问，缺一项就回去补）

1. **风格定了吗？** `# 定调` 第一句是不是一个明确的风格词（写实电影 / 魔幻超现实 / 赛博未来 / 国画古风 / 日系胶片）？**没参考图时这条是生死线。**
2. 段落是否齐、顺序是否对（定调 → 主体 → 参考锁定 → 动作 → 运镜 → 环境 → 声音 → 要求）？声音段**允许拆成 `## 背景音`+`## 台词` 或并入 `## 动作`**，只要信息齐。
3. **`## 要求` 段是否每条都带前缀？有没有裸句子？**（这条是硬红线）
4. **声音三件事是否齐**：BGM 有没有给 BPM/风格/鼓点（**不能写曲名**）；台词有没有秒数；说话有没有声明"不打断动作"？
5. **参考图模式下，是否复述了参考图的外观细节？**（复述了 → 删掉，改清单式锚定）
6. **清单式锚定是否写全**：头饰、耳饰/手饰、发色与发型、服装颜色与款式、腿饰、鞋款？
7. **被预处理遮住的部位，是否还残留外观描述？**（残留 → 删干净）
8. **运镜是否只写了一个主运镜，且没踩"大幅度运镜"红线**（甩镜/整圈环绕/瞬间变焦）？舞蹈片是否确认了全身入画 + 正面机位？
9. 提交前是否去掉了 Markdown 代码围栏（` ``` `）和"以下是提示词"这类寒暄？

## 生成后自检闸门（抽帧 14 项）

**先抽帧，再看。** 视频看不出问题，抽帧能暴露 80% 的毛病——尤其首帧与末帧，是"一致性衰减"的照妖镜。

```bash
# 3 帧拼图：第 8 帧（开头） / 第 120 帧（中段） / 第 230 帧（末段）
ffmpeg -y -i out.mp4 \
  -vf "select='eq(n\,8)+eq(n\,120)+eq(n\,230)',scale=440:-1,tile=3x1" \
  -frames:v 1 -q:v 3 sheet.jpg

# 需要看运镜轨迹时抽 6 帧
ffmpeg -y -i out.mp4 \
  -vf "select='not(mod(n\,40))',scale=320:-1,tile=3x2" \
  -frames:v 1 -q:v 3 sheet6.jpg
```

|---|---|---|
| 1 | **主体一致性** | 是不是同一个人？五官、脸型、发色有没有漂 |
| 2 | **服装一致性** | 颜色/款式/长度/面料/腰线是否与参考图一致？有没有被"重新设计" |
| 3 | **指定元素** | 用户点名要出现/要消失的东西，是否真的出现/消失了 |
| 4 | **场景一致性** | 建筑结构、栏杆走向、远景有没有被重建（环绕镜头高发） |
| 5 | **动作完成度** | 要求的动作有没有做到位？舞蹈片看**节拍与动作单位是否真的卡点**，还是变成慢速飘舞 |
| 6 | **运镜意图** | 是不是要的那种镜头（正面平视/正面环绕/自下而上）？**有没有撕裂、接缝、结构塌陷** |

| 11 | **氛围与季节** | 遮住人物只看背景，能否一眼认出用户要的季节与场所 |

| 13 | **声音** | BGM 是否出来且风格对味（不是随机罐头音）？台词能否听清、口型是否对得上？**有没有出现"说话时动作停住"的音画互斥**？有没有多余字幕/水印 |

### 判定规则（默认只判不重试）

| 情况 | 动作 |
|---|---|
| **1–14 任一不过** | 写进检查报告：标明哪一项、由哪句提示词导致、建议怎么改；**不自行重生成** |
| 结果基本可用，只有小瑕疵 | 正常交付 + **主动标注瑕疵**（如"末段 2 秒脸开始漂，建议剪到 7 秒"） |
| 任务报错 / 0 个文件 / 文件损坏 | 允许不请示重试 **1 次**；仍失败就把错误原样报给用户 |
| 用户已明确说"按这个改，重出" | **这时才**发起下一次调用，并同样回到"自检 → 报告" |

**禁止：** 用自己的审美判断代替用户授权，连调多次"碰一条好的"。

## 常见问题

### 问题 1：服装被"重新设计"了（裙子变长/变短、印花消失、吊带没了）

**根因：** 提示词复述了服装外观（与参考图冲突）＋ 服装每帧重画 ＋ 动作抢走注意力。
**解决：** 删掉服装的具体描述 → 改成"清单式锚定（只点类别）"→ 加"一比一还原，不得增删改"→ 降低动作幅度。见《失控模式 A》。

### 问题 2：明明说了"不要参考脸/鞋"，模型还是照搬

**根因：** 参考图像素权重高于文字，且否定句常被理解成"存在"。
**解决：** 先用 `--preset face` / `--preset shoes` 遮掉 → 再在 `## 要求` 写正面声明 + 反面排除双句。见《失控模式 B》。

### 问题 3：末段换脸（前 5 秒像，后 3 秒不像）

**根因：** 一致性随帧数衰减；大动作加速衰减；PixVerse 尤其明显。
**解决：** 动作降级到 L1/L2；把大动作放前 3 秒；成片**剪到 6–7 秒**；或换 Kling。

### 问题 4：环绕镜头把场景"重建"了

**根因：** 环绕要求模型补出参考图里没有的角度，它只能"编"，于是栏杆、柱子、远景全变。
**解决：** 有明确建筑结构时不用环绕，改"缓慢推近 + 轻微平移"；或接受"只拍人、背景虚化"。

### 问题 5：脚下出现悬空的高跟鞋 / 脚与鞋错位

**根因：** 脚部是最难画的部分，参考图里鞋带一复杂，环绕或抬腿时会"脱离"。
**解决：** 避免抬腿/绷脚背动作；必要时用 `--preset shoes` 遮住参考图脚部，让模型重画一双简单的鞋；或在 `## 要求` 写"双脚稳稳踩在地面，鞋与脚贴合"。

### 问题 6：运镜过大导致穿帮

**现象：** 摇/移/拉远之后露出没画好的地面、断掉的栏杆、糊掉的边界。
**解决：** 一条片子一个主运镜、幅度减半；景别不要从一个极端跳到另一个极端。

### 问题 7：视频"卡住"很久没动静

**根因：** 视频本来就是 3–5 分钟；任务排队还可能更久。
**解决：** 按《轮询纪律》等，**绝不重复提交**（重复提交 = 重复扣费）。状态 error 才重试，且只重试 1 次。

### 问题 8：竖屏没生效，出来还是横屏

**解决：** 显式传 `portrait_mode: true`；提示词里也补一句"竖屏 9:16"。两者都写最稳。

### 问题 9：同一个提示词两次结果差异很大

**根因：** 视频模型随机性远高于图片模型，首帧之外基本不可复现。
**解决：** 不要指望"微调一个字再出一版"能精准复现；参数要动就动"整段"（动作段 / 运镜段），别在细枝末节上反复试——**这是最烧钱的试法**。

### 问题 10：交付的片子音轨不对——随机罐头音，或干脆没声音

**根因：** 提示词没写 BGM，或只写了曲名（模型不认识曲名，只能给通用音）；也可能模型本身不给人声。
**解决：** 按《声音设计》写 BPM + 风格 + 鼓点/低频 + 情绪；判过"曲名换要素"这一步。仍不对就**本地换**（不花生成费）：
```bash
ffmpeg -y -i in.mp4 -an -c:v copy silent.mp4          # 去音轨
ffmpeg -y -i in.mp4 -i bgm.m4a -shortest -c:v copy -c:a aac out.mp4  # 换配乐
```

### 问题 11：想让人物做"抬眼看镜头 + 微笑 + 抬手 + 转身"四个动作

**根因：** 10 秒装不下，模型会挑一个做，或全做成"糊动作"。
**解决：** 砍到 2 个以内，且用时间轴分段写清"第几秒做什么"。见《时间轴分段写法》。

### 问题 12：参考图是半身/特写，却要生成全身视频

**根因：** i2v 只能"延续"参考图构图，补不出参考图里没有的身体与腿。
**解决：** 换一张全身参考图；或接受"半身动态"，把 `## 环境` 写足让画面有信息量。

### 问题 13：画面撕裂、边缘接缝、结构塌陷

**根因：** 运镜幅度超出了模型能"编"的范围——它要补出画面外根本不存在的角度，补不出来就撕。
**解决：** 砍掉大幅运镜（甩镜、整圈环绕、瞬间变焦、极端景别跳变），改正面平视 + 轻微推近；环绕角度压到 90–120° 以内；能靠**主体动作**制造动感就别靠镜头。见《视角与运镜：优选与避雷》。

### 问题 14：风格全跑了，出来像电商图和网红滤镜

**根因：** 风格词没写在最前面，或根本没写。模型于是回到默认审美——"干净、明亮、无个性"。
**解决：** 把风格写成 `# 定调` 的第一个词，紧跟一条反向排除（`【禁止】塑料感、CG 感、网红滤镜`）。**没有参考图时这是必做项。**

### 问题 15：跳的舞不对味——要么慢动作飘舞，要么干脆站着

**根因：** "跳热门舞蹈"对模型没有信息量，它只抓到"有动作"。
**解决：** 翻译成可观察动作 + 节奏：`每 2 拍一个动作单位`、`双脚交替点地、胯部左右摆动、手臂胸前上下波浪`、`动作干脆利落`。同时按 L3 处理：剪到 5–7 秒、优先 Kling、别叠环绕。

### 问题 16：想让人物有情绪，但脸在全身景别里就是一张小脸

**根因：** 全身景别下脸只有几十像素，微表情根本读不出来。
**解决：** 要情绪就单独给一条 `超近距离面部特写，只拍到眉眼与鼻唇`；**特写与全身是两条片子**，不要在同一句里既要全身又要微表情。

### 问题 17：一说话动作就停了（音画互斥）

**根因：** 模型把"口型驱动"和"骨骼动作"当成互斥任务，先锁哪个就只剩哪个；"先……再……""说完再"这类时序词会明确让它排队做。
**解决：** ① 删掉时序词，改写成"边……边说"；② 按秒把两件事**叠在同一时段**；③ `## 要求` 加 `【必须】说话不打断动作，口型与肢体同步` + `【禁止】说话时动作停止`；④ 动作从 L3 降到 L2；⑤ 真要两全就拆两条片子后期剪。见《关键问题：说话与动作互斥》。

### 问题 18：台词被吞字，或者口型对不上

**根因：** 台词太长（模型能稳定处理的只有 5–12 字）、语速无描述、全身景别下嘴太小。
**解决：** 砍到 10 字以内；写 `语速偏慢`；**给台词配特写或半身景别**（全身景别对嘴型本来就难）；必要时后期 TTS 配音再用 `adelay` 对齐。

### 问题 19：BGM 和画面节奏对不上

**根因：** 只写了风格没写速度与重音，模型给的是"通用循环"，不是"卡点"。
**解决：** 补 `BPM 数值` + `每 2 拍一个重击`；舞蹈片把 `## 动作` 的动作单位与 BPM 对齐（120BPM 四四拍 ≈ 每 0.5 秒一拍）；对不上就后期用 ffmpeg 重配乐。

### 问题 20：长视频接起来，人物像"重来一遍"（姿态跳变）

**根因：** 续写段把参考图当成"一张新首帧"，从站姿重新起手，而不是接着上一段的姿态往下做。
**解决：** 提示词写 `从参考图的姿态继续动作，不要从头开始`；`## 要求` 加 `【禁止】重新站定、重新构图、切换镜头`；动作降到 L1；末帧挑**最清晰**的那一帧（糊帧会诱发模型重排画面）。见《长视频》。

### 问题 21：越接越不像，第 4 段已经换人了

**根因：** 每接一段，五官与服装细节再漂一点，误差累积；末帧质量也在逐段下降。
**解决：** 段数压到 2–3 段；每段抽帧后复核服装与发饰；换参考帧时用 `pick_tail_frame.py` 重新挑清晰帧；实在不行回到原图重开一条（**要用户同意，等于作废已生成段**）。

## 最佳实践

1. **风格先行**：`# 定调` 第一个词就写风格，配一条反向排除；**没有参考图时必做**
2. **默认全身 + 舞蹈 + 正面视角**：需求没说明时按这套基线走，别每次重新问
3. **声音单独成段**：默认合并成 `## 声音`；要素多就拆 `## 背景音` + `## 台词`；口型与动作强耦合才并进 `## 动作`
4. **BGM 只写要素、台词要标秒**：BPM/风格/鼓点，不写曲名；台词 5–12 字 + 第几秒说 + "边说边做不打断动作"
5. **一次一调用**：先出一条、抽帧自检、出报告，等用户放行再追加
6. **前缀刚性**：`## 要求` 段每条都以 `【必须】/【重要】/【禁止】` 开头，无裸句
7. **参考图不复述**：只给抽象强指令 + 类别清单，不写具体外观
8. **先遮后说**：不想沿用的部位先预处理遮掉（没工具就请用户抠），再写排除句
9. **一个主运镜**：推、拉、环绕、升降只选一个；大面积运镜是撕裂的直接原因
10. **动作降级保一致**：L1 微动最稳，L3（含舞蹈）只放前 3 秒、成片剪短
11. **首尾帧定生死**：抽帧先看第 1 帧与最后 1 帧，一致性衰减全在这里
12. **声音不对先本地救**：换配乐、插配音都不花钱；别为了一条音轨重新生成
13. **本地后期免费**：剪短、拼接、转竖屏、换配乐用 ffmpeg 做，不必重新生成
14. **长任务守纪律**：3–5 分钟正常，禁止因"看起来卡住"而重复提交
15. **报告要诚实**：小瑕疵主动标注（"末段脸开始漂，建议剪到 7 秒"），不装作完美

## 注意事项

1. 视频生成是长任务，**默认 3–5 分钟**，轮询不要空转、不要重复提交
2. 每次调用通常返回 1 个视频文件（少数工具多段），拿到 URL 必须立刻落盘
3. 描述词用中文，四家模型对中文理解都不错
4. **风格必须写在最前面**，仅一个主风格；混搭等于没有风格
5. **参考图模式下，文字与参考图是竞争关系**：写得越具体，冲突越大
6. **被遮罩的部位不要再写外观描述**，否则模型会按文字重画
7. `scripts/prep_reference.py` 的预设是起点不是答案，**必须 `--preview` 复核再上传**
8. 遮罩要"宁大勿小、横向整条带"，紧框容易漏掉下巴/鞋跟
9. 没有 OpenCV/无法本地处理时，**把抠图交给用户并给清晰清单**，别硬用文字压参考图
10. 一条片子不叠加两个以上主运镜；**大面积运镜会撕裂**
11. 时长与一致性成反比，超过 10 秒要分段；舞蹈片成片剪到 5–7 秒
12. **BGM 只写音乐要素**（BPM/风格/鼓点/低频/情绪），**写曲名等于没写**
13. **台词控制在 5–12 字并标秒**；说话必须声明"不打断动作"，否则音画互斥
14. 声音段摆法自由（合并/拆分/并入动作），但**台词、秒数、声线三样不能少**
15. 音轨不满意先本地换（`-an` / 换配乐 / 插 TTS），别为声音重生成
16. **长视频 = 多段 = 多次计费**：必须先给分段计划并拿到明确授权，一段一确认
17. **末帧续写不要取最后一帧**（多半是糊的），用 `pick_tail_frame.py` 在最后 3 秒挑最清晰帧
18. 段间接缝要单独检查 5 项（人物/服装/场景/光线/动作连续），**"从头再来"式姿态跳变最容易被看穿**
19. 交付前必须抽帧过 14 项（**第 13 项要单独听音轨**），不合格写进报告，**不自行重生成**
20. 只有"结果完全不可用"的技术性失败才允许不请示重试 1 次
